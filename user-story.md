# User Stories

This document contains the user stories for the DevOps Capstone Project.

## Account Service
- Create an account.
- Read an account.
- Update an account.
- Delete an account.
- List all accounts.

## DevOps Automation
- Automate continuous integration checks.
- Implement security headers and CORS.
- Containerize the microservice using Docker.
- Deploy the Docker image to Kubernetes.
- Create a CD pipeline to automate deployment to Kubernetes.
